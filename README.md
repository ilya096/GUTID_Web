# Virtual Sports Museum

Браузерный 3D музей спортивных достижений.

## Технологии
- Three.js + React (через @react-three/fiber)
- Vite + TypeScript
- Zustand (состояние)
- MUI (UI)

## Установка и запуск

```bash
npm install
npm run dev   # http://localhost:5173
```

## Сборка

```bash
npm run build
```

## Деплой на GitHub Pages

```bash
npm run build
# Потом закоммитьте dist/ в ветку gh-pages
```
