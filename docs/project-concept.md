# Project Concept: Virtual Sports Museum

## Название проекта (рабочее)
Virtual Sports Museum — виртуальный спортивный музей университета

## Жанр и формат сессий
Виртуальная выставка / образовательный опыт. Браузерный 3D-просмотр. Типичная сессия: 5–10 минут.

## ЦА и ключевое обещание
**ЦА:** Широкий публичный доступ — студенты, выпускники, абитуриенты, гости университета, интересующиеся спортивной историей.  
**Обещание:** «Почувствуй себя частью истории спортивных достижений университета» + «Пойми масштаб достижений» через личную встречу с артефактами в иммерсивном пространстве.

## Core loop (кратко)
1. Вход в музей из браузера (без установки).
2. Выбор режима: свободный explore или тематическая аудио-экскурсия.
3. Перемещение по залу, осмотр 3D-объектов и 2D-плакатов.
4. Приближение к 3D-объекту → всплывающая info-панель с текстом и медиа.
5. В аудио-режиме: фиксированный маршрут с остановками у ключевых экспонатов и озвучкой от диктора.

## Прогрессия (кратко)
Нет геймификации и долгосрочной прогрессии. Цель — разовая или периодическая экскурсия. Есть тематические ветки аудио-гида для сегментации интересов (футбол, хоккей, олимпийцы и т.д.).

## Модель дистрибуции
Полностью бесплатный публичный доступ. Без подписок, IAP, paywall-механик. Аналитика/телеметрия — P1.

## Границы MVP
- Один зал.
- 10–15 интерактивных 3D-объектов с info-панелями.
- 30–40 2D-плакатов на стенах.
- Два режима: свободный explore + аудио-экскурсия с тематическими ветками (фиксированный маршрут).
- Браузерный доступ (WebGL/Three.js или аналоги).
- Аудио от одного диктора (запись уже есть).

## Ключевые риски
- Конвертация архивных медиа в оптимизированные 3D/2D-ассеты без потери качества.
- Производительность в браузере на слабых устройствах (оптимизация мешей, текстуры, LOD).
- Доступность и юзабилити на мобильных (P2), VR (P3).
- Сопровождение контента: процесс обновления экспонатов без перевыпуска билда.
